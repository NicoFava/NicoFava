## 🚀 Progetti Principali

- 💥 **[atlas-hzz4l-analysis](https://github.com/NicoFava/atlas-hzz4l-analysis)**: Analisi dati basata su PyROOT per la ricostruzione del decadimento del Bosone di Higgs nel canale $H \rightarrow ZZ^* \rightarrow 4\ell$. Sviluppata su 10 fb⁻¹ di ATLAS Open Data (13 TeV), include pipeline batch, cutflow cinematici e produzione di plot da pubblicazione con ratio pad e incertezze statistiche.
- 🔬 **[higgs-production-analysis](https://github.com/NicoFava/higgs-production-analysis)**: Analisi cinematica per l'identificazione dei meccanismi di produzione del bosone di Higgs (VBF, ggF, WH, ZH) ad LHC. Combina simulazioni Monte Carlo (MadGraph5, Pythia8, Delphes) e analisi di dataset "ciechi" tramite PyROOT, concentrandosi sull'isolamento del segnale Vector Boson Fusion (VBF).
- 🧊 **[icecube-neutrino-analysis](https://github.com/NicoFava/icecube-neutrino-analysis)**: Ricerca di sorgenti puntiformi di neutrini astrofisici utilizzando i dati pubblici di IceCube (Tracks 2008-2022). Implementa un'analisi di massima verosimiglianza non binnata (tramite SkyLLH) e stima del fondo via data scrambling, producendo mappe celesti (HEALPix) e scan di p-value.
- 🔭 **[auger-anisotropy-scan](https://github.com/NicoFava/auger-anisotropy-scan)**: Una suite avanzata in Python per l'analisi statistica dei raggi cosmici ad altissima energia. Sfrutta metodi Monte Carlo ottimizzati per individuare clustering e anisotropie attorno a sorgenti extragalattiche (come Centaurus A).
- 🌌 **[juno-cosmic-muons-analysis](https://github.com/NicoFava/juno-cosmic-muons-analysis)**: Il framework in C++/ROOT sviluppato per il mio lavoro di tesi. È un metodo di analisi indipendente progettato per identificare e caratterizzare i muoni cosmici a partire dai primissimi dati grezzi acquisiti dal rivelatore JUNO.

## 🚀 Main Projects

- 💥 **[atlas-hzz4l-analysis](https://github.com/NicoFava/atlas-hzz4l-analysis)**: PyROOT-based data analysis for reconstructing the Higgs boson decay in the $H \rightarrow ZZ^* \rightarrow 4\ell$ channel. Built using 10 fb⁻¹ of ATLAS Open Data (13 TeV), featuring automated batch pipelines, kinematic cutflows, and publication-style "Money Plots" with ratio pads and statistical uncertainties.
- 🔬 **[higgs-production-analysis](https://github.com/NicoFava/higgs-production-analysis)**: Kinematic analysis to identify Higgs boson production mechanisms (VBF, ggF, WH, ZH) at the LHC. Combines Monte Carlo simulations (MadGraph5, Pythia8, Delphes) with blind dataset analysis using PyROOT, focusing on discriminating the Vector Boson Fusion (VBF) signal.
- 🧊 **[icecube-neutrino-analysis](https://github.com/NicoFava/icecube-neutrino-analysis)**: Search for point-like sources of astrophysical neutrinos using IceCube public data (Tracks 2008-2022). Implements an unbinned maximum likelihood analysis (via SkyLLH) and background estimation through data scrambling, producing HEALPix skymaps and p-value scans.
- 🔭 **[auger-anisotropy-scan](https://github.com/NicoFava/auger-anisotropy-scan)**: An advanced Python suite for the statistical analysis of ultra-high-energy cosmic rays. I use optimized Monte Carlo methods to detect clustering and anisotropies around extragalactic sources like Centaurus A.
- 🌌 **[juno-cosmic-muons-analysis](https://github.com/NicoFava/juno-cosmic-muons-analysis)**: The C++/ROOT framework I built for my Bachelor's thesis. It provides an independent analysis method to identify and characterize cosmic muons using the very first raw data from the JUNO detector.
